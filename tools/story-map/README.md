# 剧情画板

只用文本框和箭头整理故事的本地小工具。无第三方依赖、无账号，不访问外部服务。

## 打开

在仓库根目录双击 **打开剧情画板.cmd**。浏览器会打开本机地址，启动窗口保持开启。

需要 Node.js 20 或更新版本。优先使用 PATH 中的 Node；没有时尝试本机已有的 Codex Node 运行环境，不会自动安装依赖。其他电脑也需要其中一种运行环境。

也可以在仓库根目录执行：

```powershell
node tools/story-map/server.mjs --open
```

默认端口 4198；被占用时会另选端口并打印地址。只监听本机 `127.0.0.1`。

## 操作

- 点 **＋ 文本框** 添加场景，单击卡片即可在右侧编辑；双击卡片直接进入正文输入。
- 拖动文本框调整位置。正文自动换行，卡片高度随文字增长。
- 点 **连箭头**，依次点击起点和终点。支持分支、汇合、回环；不允许自连或重复的同向箭头。
- 单击箭头线条或文字，在右侧填写选择条件；可删除箭头。
- **添加后续场景** 会创建新卡片并自动连上箭头。
- 拖动空白处移动画布，滚轮缩放。底部 **适应画布** 显示全图。按住空格可从卡片上拖动画布。
- `N` 添加文本框，`Delete` 删除选中的框或箭头，`Esc` 退出连线/选择，`Ctrl+S` 立即保存。
- 工具栏撤销/重做支持最近 100 步。画布聚焦时 `Ctrl+Z` 撤销，`Ctrl+Shift+Z` / `Ctrl+Y` 重做；输入框保留浏览器原生文字撤销。刷新后撤销历史清空。
- **导出 JSON** 下载当前画板的备份；**导入** 替换当前画板，替换可撤销。画板最多 2000 个框、5000 条箭头，文件上限 8 MB。

首次带有一张五节点操作示例图，并非正式企划。可以改写或逐个删除；删错可以撤销。

## 保存与两台电脑切换

剧情内容、颜色、位置、连线统一保存在本目录 **story.json**，可用文本编辑器查看；不含账户、机器路径、修改时间。画布缩放与视角不写入文件，打开时自动显示全图。

编辑停止约半秒后自动写入 JSON。确认左下角显示 **已保存到 story.json**，再关闭页面和启动窗口。

1. 首次使用时，两台电脑都拉取整个仓库，以获得工具代码和启动脚本。
2. 电脑 A 编辑后，等待保存，关闭画板，用 GitHub Desktop 提交并推送 `tools/story-map/story.json`。
3. 电脑 B 先拉取，再双击启动画板。以后的日常剧情编辑通常只改这一个 JSON 文件。
4. 切回 A 时同样先拉取。不要在两台电脑各自编辑未同步的版本；Git 冲突仍需人工选择/合并，不会自动解决。

工具不自动执行 Git。它是交替编辑的文件同步方案，不提供多人实时协作。

## 文件变化和恢复

- 保存前检查文件版本。其他窗口或 Git 更新了文件时，旧页面会暂停保存，不直接覆盖，并提供“读取磁盘版本”。先导出当前修改，保留两个版本后再决定用哪份。
- 无本地待保存编辑时，每 4 秒检查磁盘更新；页面处于后台时暂停检查。
- 使用临时文件写完再替换原文件。浏览器会尝试在本机保存未完成编辑的恢复副本，重开同地址时恢复；这是辅助恢复，正式数据以磁盘 JSON 为准。
- 关闭前还有待保存修改时，浏览器会提示。启动服务停止或磁盘出错时，可以导出当前内容保留备份。
- JSON 无效时不会重置为空白，也不会覆盖原文件。可修复文件或从 Git 恢复，再刷新。

## 验证

```powershell
node --test tools/story-map/server.test.mjs
```

自动测试使用系统临时目录，不修改实际画板。工具独立于游戏，不读取或改写正式剧本。
