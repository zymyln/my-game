# 第一章离线试玩包

现有 ZIP 为 2026-10-17 的历史试玩版，尚未包含后续结局 CG、逐个光点渐变、妮诺表情修正、移除独立漫游/小剧场和自动向下飞离。当前改动请使用开发版验证；需要转发新版时重新打包并验证。

将 **魔女之旅-第一章-离线试玩版.zip** 直接发给试玩者即可。约 45 MiB，包含：

- `开始游戏.html`：单文件离线游戏，已经内嵌程序、样式、当前第一章文本和 30 个实际使用的 PNG 素材。
- `先看这里.txt`：解压、打开方式与操作说明。

试玩者先完整解压，再双击 `开始游戏.html`，使用电脑上的 Microsoft Edge 或 Google Chrome 打开。无需 Node.js、Codex、本地服务器、安装或联网。不要在压缩包预览或聊天软件内置预览器里直接运行。关闭浏览器页面即可退出；当前无进度存档，刷新会回标题。

素材历史备份、参考图、提示词、Git 历史、开发说明、测试、服务器脚本、未接入的支线和剧本附录均不包含在试玩包中。开发仓库仍完整保留上述文件。本轮没有发布到任何网站。

## 重新打包

在仓库根目录运行：

```powershell
node tools/package-game.mjs
```

仅开发者打包时需要 Node.js，不安装依赖。脚本从 `src/main.js` 收集浏览器模块，内联 CSS，将清单引用的独立 PNG 各内嵌一次，并嵌入第一章附录前的有效文本。独立漫游所用样例对话已不再打包。只在输出副本中适配离线模块、图像和文本读取，开发源码仍使用原本的本地服务方式。

归档使用 UTF-8 文件名及标准 DEFLATE ZIP，工具只依赖 Node 内置模块。每次运行更新 ZIP 和 `release-info.json`；后者记录生成时间、游戏来源 Git 版本、HTML/ZIP SHA-256、模块清单及素材哈希。`validation.json` 记录本次解压和实际离线试玩验证，重新打包后应重新验证。

发行目标为电脑浏览器；实际验证使用 Windows 上的 Edge，在断网状态下直接打开解压目录中的 HTML。手机与聊天软件内置浏览器不作为本轮验证目标。
