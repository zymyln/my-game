# 第一章离线试玩包

当前 ZIP 已于 2026-10-19 更新，包含主线和《不送瓶子》支线、全部现行 CG 与立绘、六段幸福回忆、地图和声音补强、剧情快进。

将 **魔女之旅-第一章-离线试玩版.zip** 直接发给试玩者即可，约 **59.4 MiB**。解压后只有：

- `开始游戏.html`：单文件离线游戏，内嵌 20 个浏览器模块、样式、两份有效剧本和 37 个独立 PNG。
- `先看这里.txt`：打开方式与操作说明。

试玩者完整解压，再双击 HTML，使用电脑上的 Microsoft Edge 或 Google Chrome 打开。无需 Node.js、Codex、本地服务器、安装或联网。不要在 ZIP 预览或聊天软件内置预览器里运行。当前无进度存档，刷新返回标题。

## 操作

WASD / 方向键移动，E 交互，空格继续，Esc 暂停，F 全屏。按住 Ctrl 快进、松开恢复，也可点击快进按钮切换；遇到选择、行走与暂停自动停止。选项只用鼠标左键确认。餐厅调查会影响后续分支，音量与配乐试听在声音面板中。

## 验证

Windows 原生 Expand-Archive 解压通过。ZIP、HTML 与全部 37 张内嵌图片 SHA-256 核对一致，制作备注和主线附录未打包。

Edge 断网打开实际解压 HTML，原文件无测试修改时验证标题启动、开场飞行、落地与行走。另通过临时浏览器运行时定位到解锁选项，分别播放两条续接至结局：支线围裙、月下同行、好结局三张 CG；主线六张回忆、送别 CG、两段飞离与尾声 CG。快进、左键选择与暂停恢复通过，浏览器错误及外部网络请求均为零。明细在 `validation.json`。此轮未重跑从标题开始的全部手动行走，电脑浏览器为发行目标，手机和聊天内置浏览器未作为发行环境验证。

## 重新打包

开发者在仓库根目录执行 `node tools/package-game.mjs`，仅需已有 Node.js，不安装依赖。脚本收集 main 的浏览器模块和清单 PNG、主线附录前文本及支线正文，内联 CSS，只在输出副本中适配离线资源。源文件、图片原件与剧本不改。

打包后更新 ZIP 和 `release-info.json`，后者记录生成时间、游戏来源 Git 版本、ZIP/HTML 哈希、模块与图片清单。`validation.json` 需针对新包重新验证。未发布网站，也未向其他人自动发送文件。
