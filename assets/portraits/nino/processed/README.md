六张均为 1024×1536 RGBA PNG。保留遮住一眼的黑发、破旧头巾、衣服磨损、粉色裙装和全身鞋子；只移除背景，不为人物修补服装。平常与害怕各自作为动作基准，同动作差分沿用对应处理版身体，尽量减少切换跳动。两组手势和原始头身构图不同，不能宣称六张身体轮廓逐像素一致，接入游戏时仍需核对脸部大小和显示位置。

使用内置 imagegen 编辑，提示词见 [processing.md](processing.md)。AI 编辑可能改变细微线条、颜色、衣服纹理或面部细节，原图完整保留。生成工具可能把透明区域底层 RGB 显示成暗色；应以浏览器实际透明合成为准。校验数据见 `validation.json`。

双击 [全立绘校对页](../../preview.html)，选择妮诺表情和浅/深/棋盘底色检查。`nino_down` 采用用户的平常图，不额外强制改变头部姿势；保留平常、慌张、惊恐、泪目、微笑、空洞之间的情绪区别。
