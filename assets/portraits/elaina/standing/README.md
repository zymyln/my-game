# 伊蕾娜站立五表情 · 透明处理版

五张已登记到 `assets/manifest.json`，游戏按当前主线切换站立表情。原图在 `../approved/standing-expressions/`，与这里的处理版分开保存。

| 文件 | 表情 |
|---|---|
| `elaina_standing.png` | 平常 |
| `elaina_standing_smile.png` | 微笑 |
| `elaina_standing_blank.png` | 无语 |
| `elaina_standing_surprised.png` | 惊讶 |
| `elaina_standing_serious.png` | 正色 |

五张统一为 **1024 × 1536 RGBA PNG**，具有真实透明通道。微笑图先做背景移除与下缘清理，其余四种表情以同一张处理后的身体为编辑基准，参考用户对应表情，减少独立生成导致的构图变化。生成器预览可能把透明区域的 RGB 显示为暗色；浏览器叠在棋盘、浅色、深色背景上检查，背景区域实际透明。

使用内置 imagegen 编辑工具，未使用 CLI/API，未安装依赖。提示词见 [processing.md](processing.md)。AI 编辑可能改变原图的局部线条、颜色或细节，并非逐像素无损抠图；不覆盖原图，也不把处理版视为重新确认的角色定稿。

## 检查

- 双击 [preview.html](preview.html)，直接在本地浏览器比较五种表情。可选择棋盘、浅色、深色或草原绿背景，也可连续切换。
- `validation.json` 记录浏览器读取到的尺寸、透明/半透明像素数量、可见边界及脸部以外的像素差异。可见边界在五张图间最多相差 2px；人物位置基本统一，但身体颜色与线条仍有小差异，不宣称身体逐像素一致。
- 浅色和深色背景复查没有原来的大块底色。平常版嘴角已收平，微笑版保留浅笑；无语的半睁眼、惊讶的微张嘴与正色的眉眼可辨认。
- 已在游戏实际显示尺寸核对脸部、宽帽檐与对白框遮挡；其他三个姿势的透明处理版见 `../poses/`。
