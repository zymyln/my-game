# 艾米尔三表情透明立绘

| 原图 | 处理版 | 使用方式 |
|---|---|---|
| 艾米尔 平常.png | `emil_neutral.png` | 平常；现有 `emil_pout`、预留 `emil_serious` 暂时复用 |
| 艾米尔 沮丧.png | `emil_down.png` | 沮丧 |
| 艾米尔 灿烂.png | `emil_bright.png` | 灿烂 |

三张原件按原字节归档至 `../approved/`，副本 SHA-256 与下载目录源文件一致。透明版统一 1024×1536，先处理平常基准，再在同一画布、身体、头发构图上编辑另外两个表情。保留金发、灰蓝眼睛、蓝色上衣、米白袖子、腰带、灰裤与棕靴。

使用内置 imagegen 编辑，提示词见 [processing.md](processing.md)。重点要求保持头发与衣服颜色，仍可能有细微线条、颜色差异，不是逐像素无损抠图。透明和颜色检查见 `validation.json`；原图独立保留，便于后续复核。

已登记运行清单，主线和自由漫游显示对应图片。剧本没有“平常”标记，现有“嘟嘴”暂时显示平常图（不将其声称为真正的嘟嘴差分）；“认真”也预留相同映射，当前主线未用。未修改剧本或要求补图。游戏为艾米尔单独调整半身显示位置，小剧场氛围页同步使用灿烂图。

全部 20 张处理版可用 [全角色校对页](../../preview.html) 离线查看，原图和处理版均包含在立绘总目录的备份校验清单中。
