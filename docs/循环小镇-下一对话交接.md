## 用户明确想要的小镇

- 比较大的、内容丰富的小镇，有不同区域，旅馆等日常设施可以较齐全。
- 先处理地面小镇，先建立整体结构，人物故事随后依托空间展开。
- 建筑可以先有外观；哪些能进入、哪些需要内部地图，后续自行调整，不必每栋都开放。
- 整体世界需要一些暗处的地下设施，以及伊森留下的遗迹。地面布局阶段预留联系与入口；具体位置、功能、与仪式的关系尚未定。
- 游戏以像素风剧情探索为主，有较多地图、事件、选择和分支，不以大量动作或战斗为中心。

## 已讨论并获整体认可的分区方向

以下是可调整的规划骨架，尚未成为正式剧本地名或最终地图划分。六个区域不等于必须做成六个独立加载场景。

| 区域 | 可以包含什么 | 主要空间作用 |
|---|---|---|
| 镇口与旅人街 | 旅馆、马厩或车棚、小商店、路牌 | 旅行者抵达、住宿、认识小镇 |
| 中心广场与商业街 | 地标、集市、面包店、杂货店、餐馆或酒馆、告示栏 | 日常人流、主要道路交汇、观察循环差异 |
| 住宅区 | 民居、庭院、晾衣绳、水井、小菜园、巷道 | 居民生活、支线事件、近路与偶遇 |
| 工坊区 | 伊森的魔道具店、仓库、修理铺、手工作坊、货运后巷 | 莉迪娅生活联系、调查与线索 |
| 旧城区 | 旧建筑、封闭院落、闲置公共设施、台阶、背街 | 历史感、隐蔽通道、地下入口的可能位置 |
| 小镇边缘 | 河渠或河流、小桥、林缘、旧路、围墙或结界边界 | 空间层次、安静场景、出口与遗迹方向 |

河流、旧城历史、地标具体形式、马厩等都是布局建议，不是已定设定。伊森魔道具店已有企划依据；旅馆等丰富日常设施是用户本轮明确支持的方向。

建议的生活逻辑：旅馆靠近来客道路，广场连接主要街道，工坊留货运与后门，住宅区有支巷，旧城与新街有过渡。通过密度、地形、巷道和地标表现“大”，避免大量空地或无意义的长路。

## 秘密空间如何预留

地面草图可先标 2～3 处候选入口，例如仓库地窖、旧公共建筑封闭通道、河渠维修口。这些只是候选，不必全部采用；入口先有普通生活用途，秘密感来自后续调查。

伊森遗迹可以考虑旧城区深处或镇外边缘，但用户尚未决定。不能擅自确定“地下设施＝伊森遗迹＝最终仪式场地”，三者是否连通以后讨论。

## 布局必须尊重的现有剧情条件

- 主角伊蕾娜与副主角莉迪娅交替视角，前两次日期推进以各自调查为主，基本不正式见面，之后见面、冲突、合流。空间应支持分别活动、信息互补和后期汇合，具体路线未定。
- 伊森是魔道具店主，也是莉迪娅的养父和仪式黑幕；莉迪娅曾在店内工作。
- 循环是反复经历同一天，找到条件才能推进日期。伊蕾娜到来后需要推进三次。
- 结界封锁天上和地下，伊蕾娜飞行也无法离开。地下通道不能默认成为出镇漏洞。
- 物质环境每日刷新，食物和建筑不会因循环逐渐腐坏。累积的压抑主要来自镇民精神生命力流失；不要把后期小镇自动设计成物理废墟。
- 镇民不记得伊森，莉迪娅记得；涉及招牌、遗迹说明、店主信息的呈现要与记忆规则一起讨论，不能草率定稿。
- 单日日程、失败回滚、精神流失时钟、数值档位阈值、仪式地点等仍有待定项，先不靠猜测实现。

## 建议下一步交付
