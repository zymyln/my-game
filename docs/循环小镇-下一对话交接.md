## 正式流程与空间约束

- 四个封印，两个明面战斗封印、两个暗处解谜封印，每解除一个过去一天。诅咒力量在莉迪娅体内，不存在独立魔力库。
- D1 伊蕾娜破战斗封印 1；D2 莉迪娅破解谜封印 1；D3 伊蕾娜破战斗封印 2；D4 莉迪娅破解谜封印 2；前四天每天双方各有准备或日常戏份。
- 前三天无交集；第三天解封后莉迪娅发现伊蕾娜的存在、特殊之处与吊坠，开始起疑。认出是伊森之物，因此认定伊蕾娜是伊森派来的。伊蕾娜不知道吊坠与伊森的关系。
- 第五天最终封印在地下遗迹中心显现，伊蕾娜前往、莉迪娅跟踪，出手失败后对峙，半信半疑合作。最终封印解除，仪式瓦解、结界解除、伊森赶来，在荒凉地区/遗迹区决战。
- 吊坠为进出结界通行证；伊森用其离开后因副作用失去意识而丢失，伊蕾娜捡到并带入，宝石碎裂、本体完好。她只短暂眩晕，魔女体质差异是否作为伏笔回收待定。
- 战斗封印为演出加限时选项，3～4 节拍、每组 2～3 选项，普通 3～5 秒/紧张 1～2 秒；超时有负面反馈，但封印必解、日期必进。影响完成质量、介入度、独白和分支标记，不做敌人 AI/战斗数值/技能或复杂框架。
- 解谜为探索、同源力量痕迹感应与低难度小谜题，解错轻惩罚；具体形式待定。莉迪娅拆解/反向利用，伊蕾娜击碎。
- 结界封锁天空地下，地下入口不默认成为离镇漏洞。每日物质刷新，旧城/废墟为原有状态，不是循环造成小镇逐日物理腐坏。
- 镇民不记得伊森，莉迪娅记得。招牌、署名、物证与古代记录的呈现须核对记忆规则。
- 保留介入度/信任度及好坏结局矩阵；前四天为主要积累窗口，正式见面后不补课。
