# 第一章 瓶中的幸福 剧本

> 基底：小说《魔女之旅》第一卷 第六章
>
> 用途：供剧本精修与程序实现。旁白＝伊蕾娜视角的描述与内心话。
>
> 对应的游戏数据是 `content/dialogue.json`，ID 规则见 `docs/contract.md`。

## 制作前提

- 全章单线，没有分支和选项。
- 互动没有分支：玩家走地图、切换场景，点击几处地方调查（标记为【可点击调查】）。
- 结尾按原作留白，不给答案。

## 设定：瓶中的光点

瓶中每一颗光点，代表一段被收集来的幸福。艾米尔把人和动物感到幸福的瞬间变成魔力，收藏在瓶子里。

- 瓶里画的是光点，不是雾。画面上的数量只是表现，不代表剧情上的确切数字。
- 开瓶时飞出的光点，化成暗场里那六段看得见的幸福。六段是「看得见的部分」，不代表瓶里只有六段。
- 不要再把瓶中的东西写成白雾。SH-10 修复碎杯时的白雾是魔法自身的雾，与瓶子无关，那一处保留。

## 符号说明

- **旁白：** 伊蕾娜视角的描述与内心话，画面上不出现说话者。
- **角色[表情]：** 实际说出口的台词，方括号内为立绘表情。
- **【演出】：** 给美术与程序的镜头提示，不是台词。
- **【可点击调查】：** 玩家点开才出现的文本，看不看都不影响剧情。
- **角色[表情]（心）：** 角色没说出口、只写在旁白里的心理活动。

## 演出的做法

演出分两级。第一级是基础手段，任何镜头都只用这四件事：黑幕淡入淡出、切换立绘表情、播放音效、停留等待若干秒。没有【演出】这一行的镜头，就是普通对话：显示立绘、把台词逐条播出来即可。

第二级是魔法物件动画，目前有两个，程序用参数化的画布动画绘制，不需要额外的物品图片：

- **幸福的魔法瓶**（SH-04、SH-12）：瓶内十四颗光点缓慢漂浮，带微光和短轨迹；开瓶时瓶塞浮起，光点先从瓶内位置汇向瓶口，再向外逸出。开瓶动画约 3.4 秒。
- **碎杯与还原**（SH-10）：杯身拆成八片，沿弧线旋转飞出、落地时做透视压缩；还原时白雾、魔法环与光点引导碎片沿弧线归位，旋转角与形状回到原值，最后合成完整杯身。碎裂约 1.8 秒，还原约 3.2 秒。

动画播放期间锁定下一句，暂停会同时冻结动画。系统开启「减少动态效果」时，动画改为约 0.7 秒的静态变化。

音效默认关闭，可随时打开。目前有玻璃碎裂、开瓶、还原三种短音效，没有背景音乐。

有一处要留意：SH-10 的四个演出触发点，程序目前靠识别旁白里的关键词（匡啷、碎了一地、白雾…轻抚、碎片聚集回溯）。改写这四句必须同步通知程序端。

## 立绘与表情备查

立绘排布全章统一：左侧固定为伊蕾娜，右侧为对话对象。

| 角色 | 表情（剧本里写的） | face 文件名（不含扩展名） |
|---|---|---|
| 伊蕾娜 | 站立·平常 / 站立·微笑 / 站立·无语 / 站立·惊讶 / 站立·正色 | `elaina_standing` / `elaina_standing_smile` / `elaina_standing_blank` / `elaina_standing_surprised` / `elaina_standing_serious` |
| 伊蕾娜 | 思考·平常 | `elaina_thinking` |
| 伊蕾娜 | 摊手·微笑 | `elaina_explaining` |
| 伊蕾娜 | 扶帽·得意 | `elaina_confident` |
| 艾米尔 | 灿烂 / 嘟嘴 / 沮丧 | `emil_bright` / `emil_pout` / `emil_down` |
| 妮诺 | 低头 / 慌张 / 惊惧 / 微浅笑 / 泪目 / 空洞 | `nino_down` / `nino_flustered` / `nino_terrified` / `nino_smiletiny` / `nino_teary` / `nino_empty` |
| 村长 | 平静 / 怒吼 | `chief_calm` / `chief_angry` |

每行的第一个表情就是那张立绘的底图，后面几个都是在这张底图上只改脸的差分。

伊蕾娜有四张姿势：站立＝正面站立（对话主用）、思考＝手抵下巴、摊手＝单手摊开解释、扶帽＝扶帽檐。其他三位只有一张姿势。

命名规则：伊蕾娜用「角色_姿势」，需要差分的姿势再接上表情；其他三位只有一张姿势，用「角色_表情」。文件名一律小写。

立绘和背景一律是 PNG，放在 `assets/` 下。同一画面同时显示两张立绘：伊蕾娜在左，对话对象在右。`face` 只表示**当前说话人**的表情，另一侧保持不变；旁白时两侧都不动。

背景文件名（不含扩展名）：`field_day`（草原·日）、`hall`（宅邸餐厅）、`gate_dusk`（村口·黄昏）、`field_dusk`（草原·黄昏）。

## SC-01　草原·日

### SH-01　开场

【演出】黑幕淡入。这一段不显示立绘。伊蕾娜站在草原上，玩家可以自由走动。

旁白：平缓的平原。风在被涂成淡绿色的草原上奔跑。

旁白：一个魔女乘着扫帚，以这令人着迷的景色为背景飞行。

旁白：不用说也知道那是谁——没错，就是我。

旁白：欣赏着似乎能洗涤身心的美景一路向前，我在草原正中间看到了孤独伫立的人影。

### SH-02　相遇

【演出】玩家走近艾米尔时触发对话。

艾米尔[灿烂]：喂——！喂——！

旁白：草原正中央，一个少年上下跳跃。他单手抱着一个玻璃瓶。

伊蕾娜[站立·微笑]：你好。

艾米尔[灿烂]：你好，大姊姊是魔女啊。好厉害喔。

伊蕾娜[思考·平常]：你在这里做什么？

艾米尔[灿烂]：我在找幸福喔！

伊蕾娜[站立·无语]：？

艾米尔[灿烂]：找幸福就是找幸福喔！

旁白：……这孩子是把幸福当成掉在路边的石头吗。

艾米尔[灿烂]：话说回来，大姊姊现在有空吗？

旁白：是要找我约会吗。不不不，怎么可能呢。

伊蕾娜[扶帽·得意]：说有空是有空，不过说忙也很忙呢。

艾米尔[灿烂]：那就是有空啰！

伊蕾娜[站立·无语]：…………

### SH-03　村子在哪

伊蕾娜[思考·平常]：话说回来，这附近有人居住的村子或是城镇吗？

艾米尔[灿烂]：村子的话在那里喔。

旁白：他所指的方位的确有个小村落似的东西孤独存在。

伊蕾娜[站立·平常]：原来如此。

艾米尔[灿烂]：顺带一提，那是我的村子喔。

伊蕾娜[扶帽·得意]：你就是村长吗？您好，初次见面，我的名字是伊蕾娜，是个旅人。

艾米尔[嘟嘴]：啊，你好，初次见面，我是艾米尔——不是啦，不是这样！是我住的村子的意思啦。

伊蕾娜[站立·微笑]：我知道。开个小玩笑而已。

艾米尔[嘟嘴]：……

### SH-04　瓶中的幸福

【演出】艾米尔手上出现幸福瓶道具，瓶内十四颗光点缓慢漂浮、带微光和短轨迹。这一段接着上一段直接播。

旁白：我看向被他保护的玻璃瓶，看见某种东西在瓶中蠢动。

旁白：定眼一看，那是一群细小的光点，宛如具有生命般在瓶内飘舞。

伊蕾娜[站立·平常]：那是什么？

艾米尔[灿烂]：这就是收集幸福的瓶子喔！

艾米尔[灿烂]：将人或动物感受到幸福的瞬间变成魔力，就能用瓶子收集起来。

伊蕾娜[站立·平常]：可以打开吗？

艾米尔[嘟嘴]：当、当然不行啊！

艾米尔[嘟嘴]：这是我为了喜欢的女生收集的，不能让大姊姊碰喔！

伊蕾娜[站立·微笑]：原来如此。

艾米尔[嘟嘴]：啊，你生气了吗？

伊蕾娜[站立·微笑]：没有，只是有点佩服而已。

伊蕾娜[思考·平常]：你喜欢的女生是谁？

艾米尔[灿烂]：是在我家工作，叫做妮诺的佣人喔。

艾米尔[沮丧]：她的表情一直很忧郁，所以我想让她幸福。

伊蕾娜[站立·平常]：所以你才会用瓶子收集幸福。

艾米尔[灿烂]：嗯！

旁白：他满怀爱意望着瓶子的表情看起来十分幸福。

旁白：我想起以前看过的书。

旁白：丈夫为了生病无法离开家里的妻子，出门游历世界，

旁白：以魔法复制看到美景瞬间的画面，带回与妻子分享的故事。

旁白：让我想想，那个故事的结局怎么了？

旁白：嗯……结局我也忘记了。

## SC-02　宅邸·餐厅

### SH-05　初见妮诺

【演出】黑幕淡出，切换到宅邸餐厅。右侧立绘先是艾米尔；妮诺走进来开口说话时，右侧换成妮诺。

旁白：村子很小。穿过并排站在村口、代替大门的两棵树，我们走了进去。

旁白：笔直的道路尽头，是一栋比其它民宅大得多的宅邸——艾米尔的家。

旁白：就这样，我突然造访了村长的家。

旁白：和十分宽敞的外观相反，屋内非常普通。

艾米尔[灿烂]：来，坐下吧。

伊蕾娜[站立·微笑]：谢谢——话说，那位佣人小姐在哪呢？

艾米尔[灿烂]：不知道？应该马上就会来了吧。

旁白：就在我跟艾米尔交谈的时候，背后传来人的气息。

伊蕾娜[站立·平常]：……啊。

旁白：眼前出现的是一个女孩子。

旁白：一跟我对上眼，她肩膀一震，像是害怕什么似地微微点头。

旁白：头发草草地扎着，有一缕垂在脸侧。

旁白：她身上的围裙装（就是女仆装呢）在娇小的身躯上显得有些太大。

旁白：领口歪着，像是被人随手扯正过。

伊蕾娜[站立·微笑]：你好——你是来自东洋的人吗？

妮诺[慌张]：咦？那、那个……

旁白：不知所措的少女，求救似地瞄了艾米尔一眼。

艾米尔[灿烂]：对喔，我的爸爸是在东洋之国把妮诺捡回家的喔。

伊蕾娜[思考·平常]：然后，就请她在这个家里作为佣人工作，是吗？

妮诺[低头]：是、是的……村长大人待我不薄。

旁白：她像照着台词念一样。而且背得很熟。

### SH-06　点菜

艾米尔[灿烂]：欸欸欸，妮诺，今天午餐吃什么？

妮诺[慌张]：啊，今、今天……应村长大人的要求，是盐烤鲜鱼。

艾米尔[灿烂]：喔喔！那个，可以的话能帮那位大姊姊做一份吗？

妮诺[低头]：……好、好的。

艾米尔[灿烂]：她说可以喔，大姊姊。

伊蕾娜[摊手·微笑]：你太客气了，谢谢你们。可是我的肚子并没有那么饿，所以麻烦分量不要太多。

妮诺[低头]：……好、好的。

旁白：跟艾米尔说得一样，妮诺的脸上全是阴暗的表情。

旁白：光看画面的话，说不定会以为我们在欺负她。

艾米尔[灿烂]：啊，对了对了。妮诺，今天吃完饭后我有礼物要送你喔！

妮诺[慌张]：咦？送、送我……吗？

艾米尔[灿烂]：嗯，要好好期待喔。

妮诺[慌张]：不、不用……不用了。如果送我这种佣人礼物的话……村长大人会生气的……

旁白：这个说法已经超越谦逊，近乎卑贱了。

艾米尔[灿烂]：安啦安啦，我会好好跟爸爸说的。

妮诺[慌张]：不，可是……

艾米尔[灿烂]：那么，这是我的命令。这样的话呢？

妮诺[微浅笑]：命令的话……

旁白：他过于直率的心意是否传进了她心里？妮诺慢慢地点头，微微露出笑容。

### SH-07　空等

【演出】两人进厨房后，这一段不显示立绘，也隐藏场景里的行走人物。玩家可以在餐厅里自由走动、调查东西；准备好后走到餐桌下方按 E 坐下，进入下一段。

旁白：接下来的时间对我来说相当无趣。

旁白：艾米尔辛勤地跑去帮妮诺的忙，把身为客人的我晾在餐厅里。

旁白：我原本也想帮忙而走向厨房，但却被他露出耀眼笑容说着

旁白：「大姊姊坐好！我们两个来做就可以了！」

旁白：没有交谈的对象也无事可做。静不下来。好想看书。

【可点击调查｜餐厅内。四个都看过，之后会多出一个选择；漏掉也照样能玩下去。】

- 墙上的画：旁白：一幅草原的画。画得不算好，但画的人应该很喜欢那片草原。
- 厨房门口：旁白：妮诺在里面洗东西。背对着我，肩膀很小。我叫了一声，她没有回头，只是肩膀绷紧了。
- 挂在门边的围裙：旁白：对她来说太大了。领口缝过一次，缝得很粗。大概是她自己缝的。
- 餐桌：旁白：很大的桌子。这么大的桌子，坐下来吃饭的却只有三个人。餐具摆得很整齐，整齐得像是不敢摆错。

### SH-09　“在东洋那里，买的”

### SH-10　碎裂的玻璃杯
