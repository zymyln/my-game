# 循环小镇 · 设定速查表

> 依据 `content/planning/loop-town/剧情企划.md` **v0.4（2026-10-20 统一更新）**整理 · 2026-10-20
> 企划实质变更后需同步更新本表。词后标 ※ 的为待定项，详见主文档 §8。

## 一句话

魔女伊蕾娜旅行途中捡到吊坠，被卷入逐日循环的小镇；她与祭品少女莉迪娅以交替视角各自解除四个封印，第四天解封后在最终封印处正式见面，随后合作对决黑幕伊森；两条人格数值轴的档位组合决定好/坏结局。

## 循环规则

| 规则 | 内容 |
|---|---|
| 循环单位 | 同一天被反复经历；找到推进条件 → 日期 +1，进入下一天 |
| 推进总量 | 共 **4 个封印**（2 战斗 + 2 解谜）；每解除 1 个 → 日期 +1；4 个全破 → 最终封印显现，必须两人合作处理 |
| 每日条件 | 每天围绕 1 个封印；线索与解法**不唯一**，两人各做各的也行，一方失败另一方仍可推进 |
| 当天失败 | 仅当**两人都没完成任何条件**才触发；失败结局 = 直接失败、玩家重打 |
| 物质 | 每日刷新：食物不腐烂、物资不短缺、镇容不自行破败 |
| 精神 | **唯一累积的东西**：镇民精神生命力逐日流失 → 镇子渐压抑（流失按什么计 ※） |
| 结界 | 伊森启动仪式同时开启；球形，封天上地下一切方向，**无人可出**（伊蕾娜会飞也出不去）；**非魔女不可入**，魔女稀少故无其他魔女进入 |
| 吊坠 | 与仪式强关联；一次性，带持有者进入结界后宝石碎裂、本体完好；伊森因吊坠遗落而无法回到结界内部；伊蕾娜捡到并带入 |
| 伊森动向 | 启动仪式 → 抹除镇民对自己的记忆 → 带吊坠离开但遗落/丢失 → 在结界完整时回不去，只能在外等待 → 最终封印解除、仪式瓦解时赶来（未获完全力量，但已取得大量仪式力量） |

### 四天时间线

| 天数 | 伊蕾娜 | 莉迪娅 | 交集 |
|---|---|---|---|
| 第 1 天 | 解除战斗封印 1 | 地下遗迹调查/准备解谜封印 1 | 无 |
| 第 2 天 | 地面寻找战斗封印 2 线索 | 解除解谜封印 1 | 无 |
| 第 3 天 | 解除战斗封印 2 | 地下遗迹调查/准备解谜封印 2 | 无 |
| 第 4 天 | 前往最终封印处 | 解除解谜封印 2，最终封印显现 | 解封后碰面 |

> 这是日期推进后的第 1～4 天，不是同一日期内反复尝试的次数。前四天的日常行动没有交集，正式碰面发生在第 4 天解封之后。第 1、3 天莉迪娅是在调查还是准备，仍待确认。

## 人物

### 伊蕾娜（主角 · 叙述者 · 不可动摇的中心）

- **动机**：逃离循环（推力型，不是被吸引来的）
- **人格三层**：自恋与毒舌是表演和补丁，不是状态 / 现实主义 + 不承认的温柔（"只是顺手""报酬不错"）/ 见证者不是拯救者
- **数值轴**：介入度（冷漠↔中间↔热心），**初始中间档 0**；测的是"给自己找借口的频率"，小事件按 +1/0/−1 结算
- **关键**：在小镇附近捡到吊坠，因吊坠与仪式的关联被卷入；魔女体质使她保留记忆、不受重置；不知道吊坠是什么。单独打不过强化后的伊森；**唯一能治好莉迪娅的人**

### 莉迪娅·奥古斯特（副主角 · 祭品 · 循环之根）

- **动机**：脱离循环 → 向伊森复仇（推力型）
- **前史**：伊森养女兼魔道具店员工；"培养"实为能量输入的仪式前置；仪式当天知道自己是工具 → 剪去长发（亮红短发=复仇象征）→"信人不如信自己"
- **数值轴**：信任度（不信任↔中间↔信任），**初始偏负面**；测的是"允不允许被靠近、被善待"
- **关键**：**全镇唯一记得伊森的人**（镇民印象良好但不知她与伊森的关系）；体术为主，战斗弱于伊蕾娜；有同源力量，优先处理暗处的解谜封印；可**引爆体内与仪式同源的能量**制造 Boss 短暂破绽，代价是自身生命力；伊蕾娜到来前已独自推进两三次（**模糊带过**，顶多一个前章讲一次）
- **误判**：看到伊蕾娜身上的吊坠，认出是伊森的东西，因此认定伊蕾娜是伊森派来的；不知道伊蕾娜是被吊坠卷进来的
- **外形**：亮红色短发；日常着装 ※

### 伊森·奥古斯特（Boss · 伪装的养父）

- **表面**：魔道具店主、口碑好、接受居民委托、一直在伪装
- **实质**：收养莉迪娅=顺手养祭品；启动仪式后带着吊坠离开但遗落/丢失，因吊坠一次性、已用于伊蕾娜，结界完整时无法回去；最终封印解除后赶来。力量用途 ※、与莉迪娅重逢态度 ※、是否有过真心 ※、莉迪娅对他的称呼 ※

## 双线结构与流程

```
莉迪娅前史（模糊）→ 伊蕾娜到来
→ 第 1 天 伊蕾娜破战斗封印 1；莉迪娅调查解谜封印 1（无交集）
→ 第 2 天 莉迪娅破解谜封印 1；伊蕾娜找战斗封印 2 线索（无交集）
→ 第 3 天 伊蕾娜破战斗封印 2；莉迪娅调查解谜封印 2（无交集）
→ 第 4 天 莉迪娅破解谜封印 2 → 最终封印显现
→ 最终封印处碰面：莉迪娅看到吊坠 → 出手失败 → 对峙
→ “半信半疑”下合作处理最终封印 → 仪式瓦解、结界解除、伊森赶来
→ 荒凉地区/遗迹区 Boss 战 → 好/坏结局
```

- **交替视角**（《底特律：变人》式）；两线信息互补不重叠，合流的张力来自玩家看着两人基于不完整信息互相判断
- **信息差**：伊蕾娜不知道吊坠是什么；莉迪娅知道吊坠是伊森的，但不知道伊蕾娜是被吊坠卷进来的；玩家两条线都玩过，知道双方各自掌握的信息
- 莉迪娅的过去以回忆碎片逐次释放，**合流前不拼出全貌**
- **前四天 = 数值主要积累窗口**；两人不见面，数值靠各自选择和间接观察积累；最终封印对峙与合作是关系兑现，不承担日常补课
- 单独推进的关系代价：莉迪娅独立成功 → 她的信任值可能降（"我又靠自己解决了"）；伊蕾娜独立成功 → 介入度可能固化（"果然还是得我来"）

## Boss 战（分工已定）

最终封印解除、结界解除后，伊森从外面赶来；在荒凉地区或遗迹区决战。

莉迪娅引爆同源能量 → 制造**几秒钟**破绽窗口 → 伊蕾娜窗口内全力输出 → 击杀。伊蕾娜单独正面打不过。

## 结局

**好结局**＝两人都非负档、且至少一人正档（三种变体共用骨架，只改谁先伸手与台词）：

| 伊蕾娜＼莉迪娅 | 不信任 | 中间 | 信任 |
|---|---|---|---|
| 冷漠 | 坏 | 坏 | 坏 |
| 中间 | 坏 | 坏（中间+中间变体） | **好**：莉迪娅先伸手 |
| 热心 | 坏 | **好**：伊蕾娜先伸手 | **好**：两人同时伸手 |

- 好结局核心：击杀伊森 → 仪式力量消失、莉迪娅体内诅咒消退（原“污染力量”一词已统一）→ 莉迪娅损伤减轻 → 伊蕾娜治疗 → 两人存活
- **坏结局核心固定**：莉迪娅死亡（引爆与否都一样被牺牲）、伊蕾娜不敌 → 直接离开、路上独自思考、**不再交代伊森和小镇后续**；各变体只微调收尾台词与独白语气
- "中间+中间"变体：破绽窗口几秒，两人各自犹豫、互相触发犹豫，窗口关闭——没有人做错，都只动了七分
