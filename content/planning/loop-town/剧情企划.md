- 版本：v0.1

- 归档日期：2026-10-18

## 一、项目定位

- 类型：剧情驱动、像素地图与人物、主要人物带立绘的同人游戏
- 主角：伊蕾娜（《魔女之旅》），中心角色不可动摇
- 副主角：一位原创角色，与伊蕾娜构成双主角结构
- 参考对象：《底特律：变人》的选择分支与多结局体验，但不追求同等的篇幅与生死抉择密度
- 核心结构：一条主线从头走到尾；中途设若干失败结局（直接失败，玩家需要重新打）；真正的分歧只在最终出现，主结局最多两个
- 体量原则：短主线、高分支密度，分支走一小段后汇回主线或直接收束成小结局，避免分支内再长分支
- 公开定位：非商业、剧情向同人，免费公开

## 二、核心题材：循环小镇

### 2.1 循环机制

- 不是“无限重复同一天”，而是“达成条件推进一天，新的一天又开始循环”的逐日解锁结构
- 每一天是一个独立的小循环，玩家在当天找到推进条件，推进到第二天，第二天开始新的循环，直到最终完全走出循环
- 每一天的循环内可设失败结局。失败结局是直接失败，玩家需要重新打。在推进节点上，如果两个人都没有推进成功，则直接失败
- 循环内的一切保持不变，不会逐渐恶化

### 2.2 副主角与循环的关联（已定方向，细节待定）

- 副主角曾经有一个关系极好、极其信任的人。那个人亲手把她推入深渊，并以某种方式开启了循环，随后离开
- 那个背叛者就是最终 Boss。想要彻底解决循环，必须击败他。他可能先离开了循环在外面，也可能一直藏在循环里某处
- 副主角身上有打败 Boss 的关键（具体是什么，待定）。单凭伊蕾娜一人打不过 Boss，必须两人合作

### 2.3 两人各自的推进理由（结构性动机）

- 伊蕾娜：单纯想逃离这个循环。循环困住了她，她不想待在这里
- 副主角：需要脱离循环，去向最终 Boss 复仇。复仇是她明确的推进动力
- 两人都是被推力推着走，而非被拉力拉着走。推力保证主线永远能推进，拉力（信任与介入）决定推进得怎么样

### 2.4 为什么只有两人能出循环

- 副主角：循环的根在她身上，只有她真正“选择往前走”，循环的根才会断
- 伊蕾娜：唯一不受循环重置影响的外来者，带着完整记忆在走
- 两人都是记得每一天的人，是仅有的能推动循环的人。镇民每天重置，不记得昨天推进到哪

## 三、主角设定：伊蕾娜

### 3.1 核心理解

- 本质是善良的人，其他更多是二次元属性（自恋、毒舌、爱财）
- 善良是底色，不是义务。她不会为了正义牺牲自己，不会因为“应该”就出手，会权衡报酬、风险和麻烦
- 道德水准不是极高，但底色善良。她的道德坐标不是“正义与否”，而是“有趣与否、值得与否”
- 旅行者身份是最容易被低估的一层：她永远有退出选项，不属于任何国家，不欠任何人，随时可以走。每一次介入，本质上都是主动放弃了退路

### 3.2 三层人格结构

**表层：自恋是表演，毒舌是节奏。** 自恋发言带有明确表演性，把自己活成一个“正在被讲述的故事”里的主角。毒舌和爱财承担调节节奏的功能，用轻快的刻薄拉开沉重场面的距离。关键：自恋和毒舌是反应，不是状态——她不会无缘无故自夸，而是在不舒服或想回避某话题时，自恋才上线。

**深层：现实主义 + 不承认的温柔。** 判断是否介入的标准只有两个问题：有人向她求助了吗？她是否有能力真正提供帮助？大多数时候至少有一个答案是否定的。“冷漠”不是残忍，是边界感。温柔在边界被越过时才显现，事后绝不承认——“只是顺手”“报酬不错”“美少女的直觉”。温柔是破绽，自恋和毒舌是补丁。哪个补丁先出现、补得多用力，说明刚才那个破绽有多大。

**叙事功能：叙述者，不是拯救者。** 她经常是事件的观察者和记录者，介入不一定改变结局。这种“见证者的无力感”是自恋表演的底色——正因为改变不了太多，才更需要用“我可是灰之魔女”的姿态体面退场。

### 3.3 游戏变量轴：介入度

- 冷漠 ←→ 中间 ←→ 热心
- 测的不是善恶，是她给自己找借口的频率：是每次都算清报酬再出手，还是偶尔不算了；是嘴上说“不关我事”然后走开，还是嘴上说“不关我事”但脚步慢了半拍
- 高值不是她变好人了，是她越来越难把温柔盖回去
- 通过日常小事件累积，每个小事件三个选项分别对应 +1 / 0 / -1。示例：有人求助，选项为“直接问要什么报酬”（0）、“先问发生了什么”（+1）、“假装没听见走开”（-1）

## 四、副主角设定

### 4.1 基本定位

- 与循环有直接关联的人，过去有重大事件
- 有一定能力的人，不是软弱的人——必须有独自推进循环的能力，才能在伊蕾娜推进失败时由她推进成功，反之亦然
- 习惯不信任他人，这是选择，不是没得选

### 4.2 过去与循环

- 曾经和一个人关系极好、极其信任对方
- 那个人亲手把她推入深渊，并以某种方式开启了循环，然后离开（或藏在循环里）
- 此后她认定“信人不如信自己”，不再信任何人的好意
- 那个人是最终 Boss。副主角必须推进循环才能追到他/找到他/确认他的下落
- 她推进循环的动机明确：脱离循环，向 Boss 复仇

### 4.3 游戏变量轴：信任度

- 不信任 ←→ 中间 ←→ 信任
- 测的是她允不允许别人靠近、允不允许自己被人善待
- 必须能被日常小事件推动，且不要求玩家提前知道她的过去——玩家通过她的反应感觉到她有过什么，而不是被告知
- 日常小事件示例：有人递东西给她（接下并道谢 / 接下但沉默 / 婉拒）；有人替她做了件事（领情 / 说下次不用 / 自己重做一遍）；有人关心她（接受 / 转移话题 / 明确拒绝）
- 核心伤口方向：她曾经信错人，代价是整个镇子困在循环里。她的不信任是自我保护——信了就可能要往前走，往前走就得承认那件事是真的

## 五、双主角结构与信息不对称

### 5.1 基本结构

- 玩家操控两个不同的人，看他们不同的故事，类似《底特律：变人》
- 两条线几乎无交集，只有偶尔见过面的关系，各自推进自己的线，合流点提前（不是到最后才碰面，而是在最终阶段之前就已交汇）
- 合流前各有自己的关键节点，决定事件走向
- 两条线靠共享锚点让玩家感觉是同一个故事：同一个循环、同一个镇子、同一个“推进条件”，只是两人各自在解自己那部分

### 5.2 推进机制

- 循环分 2-3 个推进阶段
- 伊蕾娜推进失败，副主角推进成功，则继续；副主角失败，伊蕾娜成功，也可以继续
- 代价设计：单独推进能推进主线，但不容易推进两人之间的关系。副主角独立推进成功的那天，她的信任值可能下降（“我又靠自己解决了”）；伊蕾娜独立推进成功的那天，她的介入度可能固化（“果然还是得我来”）
- 玩家自然会在“推进效率”和“关系积累”之间权衡，而非无脑切来切去

### 5.3 信息不对称

- 玩家在伊蕾娜线看到的是伊蕾娜视角的循环，在副主角线看到的是副主角视角的循环，两者互补但不重叠
- 合流时的冲击力来自“原来你那边是这样的”，而非“原来你也在”
- 玩家在 A 线知道的事，B 线角色不知道；B 线掌握的信息，伊蕾娜也蒙在鼓里

## 六、判定系统：两个变量轴与结局组合

### 6.1 变量轴总览

- 伊蕾娜：介入度（冷漠 ←→ 热心），三档为冷漠 / 中间 / 热心
- 副主角：信任度（不信任 ←→ 信任），三档为不信任 / 中间 / 信任

### 6.2 结局判定规则

好结局条件：两人都不能处于负面档，且至少一方处于正面档。即“没有人拖后腿，且有人先迈出一步”。

坏结局简化规则：只要伊蕾娜是“冷漠”或副主角是“不信任”，两人都无法真正配合，直接进入同一套坏结局骨架——副主角没有拿出关键，伊蕾娜也没有真正出手，Boss 靠两人各自硬扛被磨死，代价巨大，循环解开但两人没得到想要的东西。不因另一方的档位而改变。

最坏结局条件：伊蕾娜“中间” + 副主角“中间”。

### 6.3 好结局的三种变体（共用 Boss 战骨架，只改“谁先主动”的心理描写与关键台词）

1. 热心 + 信任：最正统。两人同时伸手，齐心协力击败 Boss，无条件的相互信任
2. 热心 + 中间：伊蕾娜先伸手，非常热心地帮助，把副主角调动起来，副主角最终选择信任
3. 中间 + 信任：副主角先伸手，对伊蕾娜无条件信任，让本来没有特别卖力的伊蕾娜最终决定出力

### 6.4 最坏结局：中间 + 中间（遗憾结局）

- 两人都做了“差不多”的事，结果是“差不多”地结束了
- Boss 战中的关键瞬间：Boss 露出破绽，需要副主角交出关键、伊蕾娜同时全力出手才能抓住，窗口只开几秒
- 副主角手已摸到关键，但看了一眼伊蕾娜，犹豫了（“她会不会接住”），慢了半拍
- 伊蕾娜魔力已聚起，但看了一眼副主角，也犹豫了（“她到底信不信我”“我付这么大代价她万一不领情”），魔力没完全推出去
- 两人的犹豫互相触发：副主角的犹豫触发了伊蕾娜的犹豫，伊蕾娜的犹豫又坐实了副主角的“果然不能信”。窗口关闭
- 代价具体化：循环虽然解开，但副主角因硬扛 Boss 最后一击，失去了某样和过去有关的东西（关键记忆或关键物品碎裂）；伊蕾娜因魔力透支或魔道具损坏，很长一段时间没法好好施法，只能徒步走下一个国家
- 最后一场戏：两人在镇口分开，副主角想说“谢谢”咽回去了，伊蕾娜想说“下次别这么逞强”换成了“报酬别忘了”。伊蕾娜独白用自恋盖住愧疚：“哎呀，魔力恢复得慢，这可得记在账上。”
- 遗憾感来源：没有人做错什么，两人都动了但都只动了七分。玩家事后清楚看到差在哪——如果当时多选一次“热心”、多选一次“信任”，窗口就能抓住。遗憾来自玩家自己前面的选择，不是角色的恶意

## 七、待定事项清单

以下内容已明确方向但尚未敲定细节，留待后续讨论：

1. 副主角的姓名、外貌、具体身份（本地人/外来者/魔女等）

3. Boss 的具体设定：他为什么开启循环、他现在的状态（已离开/藏在循环里）、他的目的
4. 伊蕾娜进入循环的方式：路过当晚循环开始 / 到达时循环已存在 / 被卷入
5. 玩家第一次见到副主角的场景：当场碰面但没深交 / 压根没碰面靠切换视角才知道
6. 循环分几个推进阶段、每个阶段的天数
7. 每一天循环内的具体失败结局设计
8. 合流点具体设在哪个阶段、合流后的主线流程
9. 好结局三种变体的 Boss 战具体流程与台词
10. 坏结局组一（副主角不信任）与组二（伊蕾娜冷漠）是否需要细分变体，还是统一骨架
11. 最坏结局（中间+中间）的完整剧本

## 八、设计原则备忘

- 伊蕾娜的中心地位不可稀释，副主角的戏份服务于“伊蕾娜是什么样的人”这一核心问题
- 分支不测试“善恶”，测试“什么能让她越过自己的边界”
- 小结局之间的差异不是好坏，是她用哪种方式把温柔盖回去
- 玩家的选择塑造的是“伊蕾娜面对无力时的姿态”，而非“改变世界”
- 失败结局是直接失败，玩家需要重新挑战，不作为叙事化的重来机制
- 工作量控制：关键节点少而重，日常选择多而轻；分支走一小段即汇回或收束，不做分支内再分支
