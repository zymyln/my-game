## 这是什么

这是与仓库现有第一章游戏分开的新游戏企划：以伊蕾娜为主角、莉迪娅·奥古斯特为副主角，围绕“逐日循环的小镇”展开的剧情驱动像素游戏。

本板块只保存设定和讨论记录，不影响当前游戏运行。当前游戏仍以 `content/script/ch1.md` 为剧本真源。

## 当前已定

- 小镇有较老的旧城区，地面废墟遗迹与旧城区相关；地下遗迹由古代魔女研究这个仪式留下，不是伊森建造的。伊森特意来到小镇，在既有遗迹中研究多年后启动仪式。
- 伊蕾娜主要往返旧城区相关的地面废墟遗迹与旅馆；莉迪娅几乎一直待在地下古代遗迹，偶尔回镇。地图规划须支持这两条活动重心。

- 副主角为莉迪娅·奥古斯特，Boss 为伊森·奥古斯特，二人是收养关系。
- 伊森的仪式以莉迪娅为祭品，抽取循环中人们的精神生命力；莉迪娅引爆同源能量制造破绽，伊蕾娜负责致命输出。
- 伊森启动仪式时开启球形结界，封锁天上与地下；伊蕾娜会飞也无法离开。她因捡到伊森的吊坠被卷入，魔女体质使她保留记忆。
- 待在结界内也会被抽取精神力，诅咒力量最终汇集到莉迪娅体内，所以伊森必须离开；他用吊坠离开后因晕眩/短暂昏迷丢失吊坠，无法再回到结界内部。
- 吊坠是进出结界的通行证且只能使用一次（伊森先用于离开、伊蕾娜再用于进入，计数待确认）：伊蕾娜带着它进入结界后宝石碎裂，本体完好。伊蕾娜只短暂眩晕、没有昏迷，这是魔女体质差异；莉迪娅看到吊坠后误以为伊蕾娜是伊森派来的。
- 最终只有好结局与坏结局两大类；“中间+中间”是坏结局的一种变体。
- “循环”指同一天被反复经历；共有四个封印（两个战斗类、两个解谜类），每解除一个过去一天；四个全破后第 5 天最终封印在地下遗迹中心显现，必须两人合作处理。
- 最终封印解除后仪式瓦解、结界解除，伊森从外面赶来；他未获得完全力量，但已取得大量仪式力量。
- 双线采用交替视角；前三天两人没有交集，第 3 天解封后莉迪娅发现伊蕾娜的存在、特殊之处和吊坠并起疑；第 4 天解除最后一个封印，第 5 天莉迪娅跟踪伊蕾娜到地下遗迹中心，出手失败后对峙，之后“半信半疑”地合作。
- 伊蕾娜初始在中间档，莉迪娅初始偏负面；日常事件和剧情选择都会改变数值。
- 物质环境每日刷新，压力来自居民精神生命力的持续流失。
- 战斗封印不做复杂战斗系统，以“演出 + 限时选项”呈现；解谜封印以“探索 + 痕迹感应 + 小型谜题”呈现。封印必定解除，选择影响完成质量、介入度、独白和分支坏结局标记。
- 前四天是玩家积累介入度与信任度的主要窗口；最终封印处的对峙与合作是关系兑现，不承担日常数值补课。
- 坏结局中伊蕾娜不敌伊森，直接离开并在路上独自思考；游戏不再交代伊森和小镇的后续。
