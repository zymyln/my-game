## 这是什么

这是与仓库现有第一章游戏分开的新游戏企划：以伊蕾娜为主角、莉迪娅·奥古斯特为副主角，围绕“逐日循环的小镇”展开的剧情驱动像素游戏。

本板块只保存设定和讨论记录，不影响当前游戏运行。当前游戏仍以 `content/script/ch1.md` 为剧本真源。

## 当前已定

- 副主角为莉迪娅·奥古斯特，Boss 为伊森·奥古斯特，二人是收养关系。
- 伊森的仪式以莉迪娅为祭品，抽取循环中人们的精神力；莉迪娅引爆同源能量制造破绽，伊蕾娜负责致命输出。
- 最终只有好结局与坏结局两大类；“中间+中间”是坏结局的一种变体。
- “循环”指同一天被反复经历；莉迪娅已成功推进日期 2-3 次，主观经历约半个月左右。
- 双线采用交替视角；前两次推进两人各自调查、几乎不见面，正式见面并发生冲突后合流。
- 伊蕾娜初始在中间档，莉迪娅初始偏负面；日常事件和剧情选择都会改变数值。
- 物质环境每日刷新，压力来自居民精神生命力的持续流失。
- 前两次共同推进是玩家积累介入度与信任度的全部窗口，第三次推进成功直接触发终局。

## 待确认

详见 [剧情企划.md](剧情企划.md) 的“八、待定事项”。当前最关键的几项是：伊森的力量用途与重逢态度、莉迪娅的日常着装与对伊森的称呼、两次共同推进的具体内容、回忆碎片分布、两人正式见面的场景与冲突，以及坏结局各变体的收尾台词。
