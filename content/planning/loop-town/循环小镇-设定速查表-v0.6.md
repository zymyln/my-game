# 循环小镇 · 设定速查表

> 依据 `content/planning/loop-town/剧情企划.md` **v0.6（2026-10-20 统一更新）**整理 · 2026-10-20
> 企划实质变更后需同步更新本表。词后标 ※ 的为待定项，详见主文档 §8。

## 一句话

魔女伊蕾娜旅行途中捡到吊坠，被卷入逐日循环的小镇；她与祭品少女莉迪娅以交替视角各自解除四个封印，第 3 天解封后莉迪娅开始怀疑她，第 5 天在地下遗迹中心正式见面，随后合作对决黑幕伊森；两条人格数值轴的档位组合决定好/坏结局。

## 循环规则

| 规则 | 内容 |
|---|---|
| 循环单位 | 同一天被反复经历；找到推进条件 → 日期 +1，进入下一天 |
| 推进总量 | 共 **4 个封印**（2 战斗 + 2 解谜）；每解除 1 个 → 日期 +1；4 个全破 → 第 5 天最终封印在地下遗迹中心显现，必须两人合作处理 |
| 每日条件 | 每天围绕 1 个封印；线索与解法**不唯一**，两人各做各的也行，一方失败另一方仍可推进 |
| 当天失败 | 仅当**两人都没完成任何条件**才触发；失败结局 = 直接失败、玩家重打 |
| 物质 | 每日刷新：食物不腐烂、物资不短缺、镇容不自行破败 |
| 精神 | **唯一累积的东西**：镇民精神生命力逐日流失 → 镇子渐压抑（流失按什么计 ※） |
| 结界 | 伊森启动仪式同时开启；球形，封天上地下一切方向，**无人可出**（伊蕾娜会飞也出不去）；**非魔女不可入**，魔女稀少故无其他魔女进入 |
| 吊坠 | 进出结界的通行证，只能使用一次（伊森先用于离开、伊蕾娜再用于进入，计数待确认）；伊森因待在结界内也会被抽取而必须离开，用吊坠离开后副作用昏迷、丢失吊坠；伊蕾娜捡到并带入，宝石碎裂、本体完好；伊蕾娜仅短暂眩晕（魔女体质差异，伏笔待定） |
| 伊森动向 | 启动仪式 → 抹除镇民对自己的记忆 → 因结界内也被抽取而必须离开 → 用吊坠离开，副作用昏迷、丢失吊坠 → 结界完整时回不去，只能在外等待 → 最终封印解除、仪式瓦解时赶来（未获完全力量，但已取得大量仪式力量） |

### 五天时间线

| 天数 | 伊蕾娜 | 莉迪娅 | 交集 |
|---|---|---|---|
| 第 1 天 | 解除战斗封印 1 | 调查/准备解谜封印 1，有日常戏份 | 无 |
| 第 2 天 | 找战斗封印 2 线索，有日常戏份 | 解除解谜封印 1 | 无 |
| 第 3 天 | 解除战斗封印 2 | 调查/准备解谜封印 2，有日常戏份 | 无 |
| 第 3 天解封后 | — | 发现伊蕾娜的存在、特殊之处和吊坠，开始起疑 | 莉迪娅单方面发现伊蕾娜 |
| 第 4 天 | 有戏份（日常/准备） | 解除解谜封印 2，四个封印全破 | 各有戏份，未正式见面 |
| 第 5 天 | 前往地下遗迹中心 | 跟踪伊蕾娜 | 最终封印处见面 |

> 这是日期推进后的第 1～5 天，不是同一日期内反复尝试的次数。前三天没有交集；第 4 天各有戏份但未正式见面；第 5 天才正式碰面。

## 人物

### 伊蕾娜（主角 · 叙述者 · 不可动摇的中心）

- **动机**：逃离循环（推力型，不是被吸引来的）
- **人格三层**：自恋与毒舌是表演和补丁，不是状态 / 现实主义 + 不承认的温柔（"只是顺手""报酬不错"）/ 见证者不是拯救者
- **数值轴**：介入度（冷漠↔中间↔热心），**初始中间档 0**；测的是"给自己找借口的频率"，小事件按 +1/0/−1 结算
- **关键**：在小镇附近捡到吊坠，因吊坠与仪式的关联被卷入；魔女体质使她保留记忆、不受重置；不知道吊坠是什么。单独打不过强化后的伊森；**唯一能治好莉迪娅的人**

### 莉迪娅·奥古斯特（副主角 · 祭品 · 循环之根）

- **动机**：脱离循环 → 向伊森复仇（推力型）
- **前史**：伊森养女兼魔道具店员工；"培养"实为能量输入的仪式前置；仪式当天知道自己是工具 → 剪去长发（亮红短发=复仇象征）→"信人不如信自己"
- **数值轴**：信任度（不信任↔中间↔信任），**初始偏负面**；测的是"允不允许被靠近、被善待"
- **关键**：**全镇唯一记得伊森的人**（镇民印象良好但不知她与伊森的关系）；体术为主，战斗弱于伊蕾娜；有同源力量，优先处理暗处的解谜封印；可**引爆体内与仪式同源的能量**制造 Boss 短暂破绽，代价是自身生命力；伊蕾娜到来前已独自推进两三次（**模糊带过**，顶多一个前章讲一次）
- **误判**：第 3 天封印解除后，发现伊蕾娜的存在、特殊之处和吊坠，认出是伊森的东西，开始起疑并认为她可能是伊森派来的；不知道伊蕾娜是被吊坠卷进来的
- **外形**：亮红色短发；日常着装 ※

### 伊森·奥古斯特（Boss · 伪装的养父）

- **表面**：魔道具店主、口碑好、接受居民委托、一直在伪装
- **实质**：收养莉迪娅=顺手养祭品；本身战力不强；因待在结界内也会被抽取而必须离开，用吊坠离开后副作用昏迷、丢失吊坠，结界完整时无法回去；最终封印解除后赶来。力量用途 ※、与莉迪娅重逢态度 ※、是否有过真心 ※、莉迪娅对他的称呼 ※

## 双线结构与流程

```
莉迪娅前史（模糊）→ 伊蕾娜到来
→ 第 1 天 伊蕾娜破战斗封印 1；莉迪娅调查解谜封印 1（无交集）
→ 第 2 天 莉迪娅破解谜封印 1；伊蕾娜找战斗封印 2 线索（无交集）
→ 第 3 天 伊蕾娜破战斗封印 2；莉迪娅调查解谜封印 2（无交集）
→ 第 3 天解封后：莉迪娅发现伊蕾娜与吊坠，开始起疑
→ 第 4 天 莉迪娅破解谜封印 2 → 四封印全破
→ 第 5 天 最终封印在地下遗迹中心显现；伊蕾娜前往，莉迪娅跟踪
→ 莉迪娅出手失败 → 对峙
→ “半信半疑”下合作处理最终封印 → 仪式瓦解、结界解除、伊森赶来
→ 荒凉地区/遗迹区 Boss 战 → 好/坏结局
```

- **交替视角**（《底特律：变人》式）；两线信息互补不重叠，合流的张力来自玩家看着两人基于不完整信息互相判断
- **信息差**：伊蕾娜不知道吊坠是什么；莉迪娅知道吊坠是伊森的，但不知道伊蕾娜是被吊坠卷进来的；玩家两条线都玩过，知道双方各自掌握的信息
- 莉迪娅的过去以回忆碎片逐次释放，**合流前不拼出全貌**
- **前四天 = 数值主要积累窗口**；两人没有正式见面，数值靠各自选择和间接观察积累；最终封印对峙与合作是关系兑现，不承担日常补课
- 单独推进的关系代价：莉迪娅独立成功 → 她的信任值可能降（"我又靠自己解决了"）；伊蕾娜独立成功 → 介入度可能固化（"果然还是得我来"）

## 封印演出基调

- **战斗封印**：不做复杂战斗系统、敌人 AI、战斗数值、技能或回合/即时框架；以“演出 + 限时选项”呈现，每个封印 3～4 节拍，每组 2～3 选项，普通 3～5 秒、紧张 1～2 秒；超时视为犹豫/失误。封印必解、日期必进，选择影响完成质量、介入度、独白和分支坏结局标记。
- **解谜封印**：探索 + 痕迹感应 + 小型谜题；符文顺序或材料/机关对应，低难度、叙事优先，解错轻惩罚；莉迪娅“拆解/反向利用”，伊蕾娜“击碎”。

## Boss 战（分工已定）

最终封印位于地下遗迹中心；解除后结界解除，伊森从外面赶来，在荒凉地区或遗迹区决战。

莉迪娅引爆同源能量 → 制造**几秒钟**破绽窗口 → 伊蕾娜窗口内全力输出 → 击杀。伊蕾娜单独正面打不过。

## 结局

**好结局**＝两人都非负档、且至少一人正档（三种变体共用骨架，只改谁先伸手与台词）：

| 伊蕾娜＼莉迪娅 | 不信任 | 中间 | 信任 |
|---|---|---|---|
| 冷漠 | 坏 | 坏 | 坏 |
| 中间 | 坏 | 坏（中间+中间变体） | **好**：莉迪娅先伸手 |
| 热心 | 坏 | **好**：伊蕾娜先伸手 | **好**：两人同时伸手 |

- 好结局核心：击杀伊森 → 仪式力量消失、莉迪娅体内诅咒消退（原“污染力量”一词已统一）→ 莉迪娅损伤减轻 → 伊蕾娜治疗 → 两人存活
- **坏结局核心固定**：莉迪娅死亡（引爆与否都一样被牺牲）、伊蕾娜不敌 → 直接离开、路上独自思考、**不再交代伊森和小镇后续**；各变体只微调收尾台词与独白语气
- "中间+中间"变体：破绽窗口几秒，两人各自犹豫、互相触发犹豫，窗口关闭——没有人做错，都只动了七分
