## 这次为什么这样改

第二稿以排水、地窖、维修空间串起地下，中心落在走廊末端。v0.7 已确认这里是古代魔女研究仪式留下的遗迹，伊森后来特意来镇研究多年；因此第三稿改为**古代研究中庭、两侧研究支翼、环绕回廊、后期利用的局部痕迹**。普通地窖和检修口退为可删减外部接口，不再决定整座遗迹的功能。

中庭位于整张图的中部，是可辨认的空间中心。上层观察廊先给玩家一个方位参照，再通过两翼的调查获得理解；下层场地从南侧前庭接近。图中的高差、遮挡和材质只表达空间层次，尚未定成地图尺寸或关卡门禁。

古代部分用连续石构、原有刻槽与嵌入式记录面形成共同外观；伊森部分用后来搬入的桌子、灯具、支架、散页和定位记号表达。具体物证、署名、回忆与揭露顺序以后依据剧本决定，不能借“新旧材质”直接让玩家知道全部真相。

## 路线与分支

主入口候选从旧城区相关地面废墟下行到 R01，经过 R02，再分流到东西回廊。图中回廊为完整环路，可绕过中心返回入口，不需要每次从头穿过所有房间。

- 西侧调查段：R02 → 西回廊 → R04 / R06 → R05，支持第一处解谜；R07 为可选停留。
- 东侧调查段：R02 → 东回廊 → R08 → R09，支持第二处解谜；R10 为短支路。
- 中心接近段：R02 → 东回廊 → 南侧转角 → R11 → 下行梯 → R13；西回廊也接南侧，图未设角色专用门。
- S1 地窖与 S3 检修口只留候选接口，不直接连通、也不默认通往镇外；先确认主要入口，再决定是否需要附加入口。

图上的路线都是空间连接提案，不规定整条路线在第一天就可走。若后续需要限制某段，应说明具体原因与反馈，不能只凭一天一个封印就画四把锁。

R03 面向 R13 的蓝虚线仅是视线，不能读成桥。伊蕾娜会飞，因此普通栏杆、沟壑、高差不能自动阻止她到达；此前中心是否可进入、最终封印未显现时如何呈现，需依据正式规则和剧情确认。此次不擅自添加禁飞场、不可见屏障或自动日期门禁。

## 五天怎么使用这张图

| 日期 | 地下空间的作用提案 | 已定与未定的界线 |
|---|---|---|
| D1 | 莉迪娅熟悉前厅、西翼和 P1 周边，穿插自己的准备与停留 | 她有地下调查及日常戏份已定；不是要求玩家当日翻遍全部房间 |
| D2 | R06 的局部提示与 R05 的解谜组合，解除 P1 | 解谜封印 1 当日解除已定；不能把同源力量写成打开所有门的万能钥匙 |
| D3 | 东翼调查、R08 的研究痕迹、R09 的准备 | 第三天解封后发现伊蕾娜和吊坠已定；具体在哪里上行、如何看到、距离多近另画局部，不宣称本地下图已解决 |
| D4 | R09 完成 P2，回廊提供回访和整理线索的空间 | 最后一个普通封印解除已定；不让残余支线强迫玩家再次走完两翼 |
| D5 | 伊蕾娜沿中心接近段前往 R13；莉迪娅利用熟悉路线跟踪 | 地图只为接近、转角和观察留位；出手在处理封印前还是过程中，以及具体分镜仍待定 |

绿色与红色虚线路线使用同一东回廊接近前庭，偏移只是为了看清标记，不是额外暗道。柱列及转角在概念图中提供跟踪演出的可能，实际视线遮挡需局部白盒验证。无需要求玩家操作潜行或尾随小游戏。

第五天最终封印显现前，不把中央场地直接画成早已亮着的最终封印。正式内容确认前可以使用普通中心遗构作为视觉预留，但不确定早期是否可到达。决战仍可能发生于荒凉地区或遗迹区，第三稿不将中心自动定成 Boss 场地，也不新增解除结界前的出镇出口。

## 信息密度与低工作量做法

每个主要空间先用 2–3 组能被一眼识别的物件构图，互动只放在其中最有信息价值的对象。例如 R08 的桌子、纸片与撑架作为同一组调查内容，首次说明用途，得到新线索后追加一个追问或短独白，不为每张纸写一段无意义文本。

西翼偏“观察旧结构并比对”，东翼偏“辨认后来利用与构件关系”，中心负责规模感和事件演出。这样可在石墙、刻槽、柱子、桌架等少量美术类别上复用，同时靠布置与用途区分房间。每一间都做机关会削弱节奏：R07 与 R14 留呼吸空间，R10 只给可选回报。

记录、对照、感应和重新理解构件支撑密度；古代结构破损是进入循环前的状态，不随重复天数自动加重。具体魔女研究内容只按已定“这个仪式”预留，不编造学派、年代、实验对象或惨案。

## 与第二稿的关系及下一步

地下空间讨论以本稿为准；第二稿的小镇地面图保持原样，相关封印位置仍需未来围绕旧城区相关地面废墟重审。第三稿不是对其全部地图编号或入口的批准。

下一次由用户先检查：研究遗迹的感觉是否符合预期；中心与两翼的关系是否清楚；莉迪娅的长期地下探索是否还有缺少的场所。确认一个方向后再深化一个局部，如 R05–R06 解谜支翼或 R11–R13 中心接近段。暂不制作像素正式图、完整室内或游戏系统。
