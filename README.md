平面像素小游戏，浏览器运行。

## 仓库内容板块

- **当前游戏：第一章《瓶中的幸福》**：本 README 其余部分介绍的游戏，程序与剧本均已接入。
- **新游戏企划：循环小镇（v0.2）**：[独立企划板块](content/planning/loop-town/README.md)，目前只有设定与文档，尚未接入程序，也不影响现有游戏。

src 目录归程序，content 目录归文本。

## 当前版本：第一章剧情

标题页只保留 **开始旅行**，按当前剧本播放第一章。独立自由漫游与演出小剧场已移除，旧的 ?effects 预览链接不再启用。主线内必要的行走、交互及餐厅可选调查保留。

剧情路线：开场 → 走近艾米尔相遇 → 谈论瓶子 → 前往餐厅 → 初见妮诺与点菜 → 可选调查/坐下等餐 → 午餐与碎杯 → 送瓶子或安慰妮诺 → 各自的送别与尾声。剧情只开放当前阶段的入口，调查完全可选。

游戏分别读取 `content/script/ch1.md` 与 `content/script/ch1_branch_b.md`，保留原台词，不读取附录或给制作者看的说明。共 24 个镜头、316 条台词/旁白、6 条幸福文字和一组选择，按路径播放。文本机修改台词后，刷新页面即可读取新稿，不需要在程序里复制修改，也不必把两份文件合并。

支线 B《不送瓶子》已接入：餐厅等候时看过墙上的画、厨房门口、围裙、餐桌全部四处调查，午餐末尾、伊蕾娜说“这不是送她礼物的大好时机吗？”之前才会出现“建议他送出瓶子／建议他安慰妮诺”。选前者保留原结局，选后者进入九镜头支线；漏看任意一处则直接继续原剧情。支线包含五句自动播放的艾米尔静思、夜里村口，以及最后两句旁白的月下同行 CG，随后以用户提供的好结局 CG 展示六句旅途后记（缺图回退白天草原），不套用原赠瓶回忆或伊蕾娜飞离。所需素材和可后补的 CG 已整理在 [支线接入清单](docs/branch-b-integration.md)。

伊蕾娜只在开场与离场骑扫帚。开场四句旁白期间低空飞入、停留，读完后落地再恢复步行；中间剧情行走保持原步行小人。村口送别及妮诺回望读完后自动骑扫帚向下飞出画面，约 2.2 秒后切到黄昏草原，从上方继续约 3 秒向下飞离，再进入尾声第一句旁白和结局 CG；两段均使用正面骑姿，不需要手动走到出口。飞行与落地均支持暂停，重新开始会清理旧演出；减少动态效果时使用较短的静止渐变。正面飞行图片缺失时自动转场进入尾声。

尾声 SH-15 从第一句起使用用户提供的黄昏草原 CG，铺满游戏画面，贯穿全部 17 句独白。此时只保留 CG 和对话框，隐藏角色立绘、顶部工具栏和额外光影；Esc 仍可暂停与恢复。窄屏保持等比、偏右取景，缺图时回退黄昏地图；返回标题或重开会清除 CG。当前开发版与 2026-10-19 更新的离线 ZIP 均已包含此改动。

六片幸福按“一个光点 → 一张回忆”循环演出：瓶内保留许多漂浮光点，每轮只有一个穿过瓶口飞出（约 1.8 秒），随后对应插画与原文一起淡入（约 0.85 秒）。完全显示后至少停留两秒，点击画面、继续按钮或按空格，先淡去（约 0.7 秒），再回到瓶子放飞下一个光点；第六张淡去后恢复对白与伊蕾娜站立平常。转场期间连点不会跳段，暂停冻结飞行、淡入淡出和阅读计时，返回标题取消未完成演出。减少动态效果缩短飞行与渐变，仍保留柔和过渡。图片完整显示，缺图时仍有瓶子与淡入淡出的原文，下一张可恢复插画。离线图集 `assets/memories/preview.html` 供静态校对，不播放此段剧情动画。

“那个眼神”处保留三秒停顿，尾声全程隐藏立绘。碎片、白雾和复原的杯子暂用程序绘图，伊蕾娜已接入四种姿势、五种站立表情，共八张透明立绘；村长平静和愤怒也已接入，不耐烦透明版已保存预留，艾米尔三张也已接入，“嘟嘴”暂时显示平常图；妮诺新版四表情也已接入，慌张暂用正常图、惊惧暂用哭泣图，最后回望使用空洞图。声音默认开启，在点击开始旅行后播放；此前保存过静音设置时沿用用户选择。

## 音乐与音效

四段原创短曲由浏览器本地合成，不下载音频、不调用服务：草原《风经过的地方》用轻柔笛音，餐厅《窗边的午后》用软钢琴，幸福暗场《被收藏的光》用钟音，黄昏《没有答案的归途》用稀疏钢琴。每段有两节编配变化，约 33–64 秒循环；另有低声部冲突氛围。当前是合成乐器试作，可以继续按试听反馈调整音色和旋律。

配乐按场景淡入淡出，SH-09 身世谈话停止配乐和环境音，SH-14 回望只留很轻的风声；SH-10 冲突与还原采用不同听感。草原有风声和间歇鸟鸣，移动时按实际行走距离播放草地或木地板脚步；调查、转场、碎玻璃、开瓶、还原及光粒子均有对应短音效，不给每句对白加提示音。

右上角“声音”控制总静音，“音量”可分别调音乐、动作音效、环境音，并试听四段配乐。关闭音量面板会恢复剧情配乐。设置只保存在当前浏览器，不影响另一台电脑；浏览器禁用本地存储时仍可使用音量控制。暂停与隐藏页面会冻结音频时钟，恢复后继续；返回标题或结尾会淡出。浏览器不支持音频时仍可继续游戏。

餐厅的画、围裙、餐桌调查卡已加入像素特写，厨房门口保留文字；缺图会自动退回纯文字。SH-10 的碎杯声与村长第一句怒吼各触发一次轻微抖屏，暂停会冻结抖动；减少动态效果时关闭抖屏。伊蕾娜也会在旁听时反应：碎杯声起转为惊讶，碎片落地的几句保持惊讶；村长开始训斥时转为站立正色，随后在还原魔法中保持摊手，结束后随她自己的台词恢复微笑。妮诺看完瓶中幸福、六张文字暗场结束后，伊蕾娜在第一句可见对白立即回到站立平常，并在妮诺落泪的旁白中保持。反应只切换人物图片，说话人姓名与高亮仍跟随实际台词。立绘沿用现行“姿势·表情”命名，素材接入进度见 `assets/README.md`。

## 主线演出

主线 SH-04 和 SH-12 显示幸福瓶，赠瓶六段采用可重复的单光点释放动画，瓶内其余光点持续保留。SH-10 播放碎裂与还原动画；关键动画完成前会锁定下一句，暂停会冻结动画。妮诺在碰撞和碎杯时使用平常立绘，村长训斥后再次开口才使用哭泣立绘。

主线也使用同一套氛围层：SH-09 餐厅逐渐转冷，SH-10 冲突时收暗、还原魔法时回暖，SH-14 左侧人物退暗、突出妮诺。SH-15 使用原色静止 CG，关闭叠加光影；缺图才显示原黄昏地图。背景镜头最多缓慢放大 2.8%，对白和按钮不缩放；不新增强制等待或音效。暂停冻结光影、背景浮尘和镜头，离开对话或重开会清除演出状态。减少动态效果时保留静态光影，关闭镜头推进及新增浮尘。

尚无战斗和持久存档，页面关闭后从头开始。

## 剧本修改与程序约定

- 程序只读 `content/`，不修改 `docs/contract.md`、现有 JSON 的字段或 ID。
- `src/chapter.mjs` 是临时只读适配层，使用现有 `SC-xx` / `SH-xx` 标题、表情表、`角色[表情]：台词`、`旁白：台词`、`（心）` 与六片光粒子标记。内部播放游标不是对外数据 ID，也不会写回仓库中的剧情数据。
- 日常微调台词或插入台词会在刷新后生效。在另一台电脑改稿时，先提交并推送，本机拉取后再刷新页面。新增角色/表情时同步填写剧本上方的表情表。若增删镜头、重排场景或更换镜头编号，需要同步调整程序端的剧情流程；未编排的新增镜头会明确报错，避免被静默漏掉。
- `content/script/chN.md` 是剧本唯一真源；`content/dialogue.json` 的 22 条历史样例及原 ID 保持不变，当前游戏不再读取或打包，不转换整章 JSON。
- 玻璃杯演出的触发点暂用 SH-10 中“匡啷”“碎了一地”“白雾…轻抚”“碎片聚集回溯”等语句识别；若重写这些演出相关句子，需要程序端一起检查画面触发。普通台词和剧情推进不依赖这些关键词。

## 在这台电脑上运行

双击 **`开始游戏.cmd`**。它会启动本地服务并打开浏览器；游玩时保持命令窗口开启，结束后可以关闭窗口。

已有 Node.js 时，也可以在项目目录运行：

```powershell
node src/server.mjs
```

打开终端打印的地址，默认是 `http://127.0.0.1:4173`。默认端口被占用时会尝试后续端口。不需要安装依赖，也不需要 API Key。不要直接双击 `index.html`，否则浏览器无法读取剧情 JSON。

## 操作

- **WASD / 方向键**：移动。
- 靠近人物、调查物或出入口后 **E**：交谈、调查或切换场景，也可以点击出现的提示。靠近调查物后也可以直接点击地图中它的位置。
- **Space / Enter**：补全当前句，再按一次前往下一句；也可以点击对话框右下角。
- **选择出现时**：只能用鼠标左键点击选项，空格、E、Enter、数字键和方向键不参与选择。Esc 可暂停；静思过场自动播放并支持暂停。
- **Esc**：暂停/继续；调查时关闭见闻卡。
- **声音：关/开、音量**：控制总静音、音乐/音效/环境音音量和配乐试听。暂停会保留当前台词、幸福文字停留计时及音频播放位置。
- **F**：切换全屏。

src/world.mjs       四张地图的碰撞、出口、交互配置与调查原文读取
src/chapter.mjs     只读剧本适配、镜头顺序与剧情阶段
src/branch-staging.mjs 支线自动静思与二人离开的演出时钟
src/memory.mjs      单光点释放、回忆淡入淡出与阅读停留计时
src/dialogue.mjs    历史样例的字段校验器，当前主线不加载
src/sound.js        三路音频混音、短音效、环境音与暂停
src/score.mjs       原创配乐乐谱和剧情声音编排
src/music.js        本地离线渲染配乐与循环尾音处理
src/audio-panel.js  音量、试听与浏览器设置保存
src/magic.mjs       魔法物品播放状态、光点与碎片运动
src/magic-art.js    主线与预览共用的魔法物品绘制
src/staging.mjs     主线光影、暗角和镜头状态
src/art.js          四处像素环境、环境微动和占位人物
src/assets.js       按素材清单加载 PNG，缺图时回退到占位
src/styles.css     界面样式
src/server.mjs     零依赖的本地静态服务
assets/            程序端接入的美术素材
content/           文本机维护的剧本与对话数据（程序端只读）

立绘在左、右两侧显示。`face` 仅更新当前说话人的表情；旁白不显示姓名，并保留两边已有的表情。素材接入方式见 [assets/README.md](assets/README.md)。

原生浏览器模块已经足够验证当前切片，因此暂未引入 Phaser 或其他新依赖。地图绘制、对话数据和素材读取分开，后续可以在保留内容格式的基础上扩展。

## 剧情快进

- 按住 **Ctrl** 临时快进，松开恢复；也可点击画面内的“快进”按钮持续播放，再点一次停止。手机可直接用按钮。
- 快进时文字直接显示，普通对白约每 0.18 秒推进；回忆、飞行、魔法和 CG 渐变按 8 倍速度播放，仍按原顺序完成。
- 遇到选择、自由行走、调查、暂停或结尾会自动停止；分支仍需鼠标左键选择，不代替玩家调查或移动。选择后需重新开启快进。
- 切到其他窗口/标签或返回标题会停止，避免回来后剧情已跳过。没有新增存档，2026-10-19 离线 ZIP 已包含快进。

主线村口送别 SH-13～14 已整体改用用户提供的双人黄昏 CG，取消该段妮诺空洞立绘；对白及回望停顿保留。读完后仍自动接两段向下飞离和原尾声 CG。

支线 SH-20 五句静思已接入旧围裙 CG，展示艾米尔看着挂在窗边的围裙，保留自动阅读、暂停与快进。原图独立归档，未修改剧本。
