# my-game

平面像素小游戏，浏览器运行。

src 目录归程序，content 目录归文本。

## 当前版本：第一章剧情与自由漫游

标题页的 **开始旅行** 会按当前剧本播放第一章；**自由漫游** 保留上一版四个场景和 22 条样例对话的体验。

剧情路线：开场 → 走近艾米尔相遇 → 谈论瓶子 → 前往餐厅 → 初见妮诺与点菜 → 自由调查/坐下等餐 → 午餐、玻璃杯与赠瓶 → 村口送别 → 黄昏尾声。剧情模式只开放当前阶段的入口，等餐的四处调查完全可选。

主线直接读取 `content/script/ch1.md` 的有效部分，保留原台词、表情、单线走向与结尾留白，不包含附录。当前读取 15 个镜头、234 条台词/旁白和 6 条幸福文字。文本机修改台词后，刷新页面即可读取新稿，不需要在程序里复制修改。`ch1_branch_b.md` 是独立支线草稿，暂未接入选项或播放流程。

伊蕾娜只在开场与离场骑扫帚。开场四句旁白期间低空飞入、停留，读完后落地再恢复步行；中间探索和自由漫游保持原步行小人。离开村口、进入黄昏草地时，先看到她起飞并向远处飞走，消失后才进入尾声的第一句旁白。飞行与落地均支持暂停，重新开始会清理旧演出；减少动态效果时使用较短的静止渐变。飞行图片缺失时仍可继续剧情。

六片幸福配有六张温暖二次元插画，图片与原文同步逐条呈现，每条至少停留两秒，点击画面、继续按钮或按空格切换；图片完整显示，缺图时回退原有文字与光点演出。暂停会保留当前图片与停留时间。离线图集见 `assets/memories/preview.html`；“那个眼神”处保留三秒停顿，尾声全程隐藏立绘。碎片、白雾和复原的杯子暂用程序绘图，伊蕾娜已接入四种姿势、五种站立表情，共八张透明立绘；村长平静和愤怒也已接入，不耐烦透明版已保存预留，艾米尔三张也已接入，“嘟嘴”暂时显示平常图；妮诺新版四表情也已接入，慌张暂用正常图、惊惧暂用哭泣图，最后回望使用空洞图。声音默认开启，在点击开始旅行或自由漫游后播放；此前保存过静音设置时沿用用户选择。

## 音乐与音效

四段原创短曲由浏览器本地合成，不下载音频、不调用服务：草原《风经过的地方》用轻柔笛音，餐厅《窗边的午后》用软钢琴，幸福暗场《被收藏的光》用钟音，黄昏《没有答案的归途》用稀疏钢琴。每段有两节编配变化，约 33–64 秒循环；另有低声部冲突氛围。当前是合成乐器试作，可以继续按试听反馈调整音色和旋律。

配乐按场景淡入淡出，SH-09 身世谈话停止配乐和环境音，SH-14 回望只留很轻的风声；SH-10 冲突与还原采用不同听感。草原有风声和间歇鸟鸣，移动时按实际行走距离播放草地或木地板脚步；调查、转场、碎玻璃、开瓶、还原及光粒子均有对应短音效，不给每句对白加提示音。

右上角“声音”控制总静音，“音量”可分别调音乐、动作音效、环境音，并试听四段配乐。关闭音量面板会恢复剧情配乐。设置只保存在当前浏览器，不影响另一台电脑；浏览器禁用本地存储时仍可使用音量控制。暂停与隐藏页面会冻结音频时钟，恢复后继续；返回标题或结尾会淡出。浏览器不支持音频时仍可继续游戏。

餐厅的画、围裙、餐桌调查卡已加入像素特写，厨房门口保留文字；缺图会自动退回纯文字。SH-10 的碎杯声与村长第一句怒吼各触发一次轻微抖屏，暂停会冻结抖动；减少动态效果时关闭抖屏。伊蕾娜也会在旁听时反应：碎杯声起转为惊讶，碎片落地的几句保持惊讶；村长开始训斥时转为站立正色，随后在还原魔法中保持摊手，结束后随她自己的台词恢复微笑。妮诺看完瓶中幸福、六张文字暗场结束后，伊蕾娜在第一句可见对白立即回到站立平常，并在妮诺落泪的旁白中保持。反应只切换人物图片，说话人姓名与高亮仍跟随实际台词。立绘沿用现行“姿势·表情”命名，素材接入进度见 `assets/README.md`。

## 演出小剧场

标题页点击 **演出小剧场**，可以直接试看片段，不需要重读整章：

- **幸福的魔法瓶**：封在瓶内的光点缓慢漂浮并留下微光轨迹；打开后瓶塞浮起，光点先汇向瓶口，再向外逸出。
- **碎杯与还原**：同一只杯子拆成八片，旋转落地并呈现落地透视；施放还原魔法后，白雾、魔法环和光点引导碎片归位，最后合成完整杯身。
- **剧情氛围**：七段光影试映，包括草原微风、餐厅暖光、谈话渐冷、冲突压迫、魔法后的缓和、妮诺回望和黄昏留白。点击“下一段光影”手动比较，或“完整演出”每五秒切换一段；这里只展示光影，不播放剧情。
- **完整演出**：连续播放当前物品的完整过程；也可以分步操作或暂停。焦点在演出画面时，空格可暂停/继续；Esc 返回游戏。右上角“声音”可控制静音，配乐跟随当前预览片段。
- 本地服务地址后加 `?effects=bottle`、`?effects=glass` 或 `?effects=mood` 可直达对应预览。预览使用独立播放状态，关闭后不会改变主线进度。

主线 SH-04 和 SH-12 显示幸福瓶，赠瓶时使用同一套开瓶动画。SH-10 的碎裂与复原同样使用小剧场的动画；关键动画完成前会锁定下一句，暂停会冻结动画。系统启用“减少动态效果”时，改用较短的静态变化。

主线也使用同一套氛围层：SH-09 餐厅逐渐转冷，SH-10 冲突时收暗、还原魔法时回暖，SH-14 左侧人物退暗、突出妮诺，SH-15 留下暮色与微风。背景镜头最多缓慢放大 2.8%，对白和按钮不缩放；不新增强制等待或音效。暂停冻结光影、背景浮尘和镜头，离开对话或重开会清除演出状态。减少动态效果时保留静态光影，关闭镜头推进及新增浮尘。

## 自由漫游

操控伊蕾娜，在白昼草原、宅邸餐厅、黄昏村口和黄昏草原之间往返。每张地图都有对应的碰撞区域、出入口、交互提示和淡入淡出。右下角的漫游路线会记录本次打开页面后到过的地方。

- 草原：靠近艾米尔，阅读 `content/dialogue.json` 中 SH-04 的 22 条样例对话。向右上方的村庄小路走，可以进入餐厅。
- 餐厅：调查墙上的画、厨房门口、围裙和餐桌。文本直接读取 `content/script/ch1.md` 餐厅调查段落的四条原文，调查完全可选，不限制出门。左下方出口返回白昼草原，右下方出口前往黄昏村口。
- 村口：两棵树间的道路连接餐厅与黄昏草原。
- 黄昏草原：可以散步，也可以沿小路返回村口。

自由漫游不会推进主线。尚无战斗和持久存档，页面关闭后从头开始。正式立绘和重要 CG 由用户后续提供。

## 剧本修改与程序约定

- 程序只读 `content/`，不修改 `docs/contract.md`、现有 JSON 的字段或 ID。
- `src/chapter.mjs` 是临时只读适配层，使用现有 `SC-xx` / `SH-xx` 标题、表情表、`角色[表情]：台词`、`旁白：台词`、`（心）` 与六片光粒子标记。内部播放游标不是对外数据 ID，也不会写回仓库中的剧情数据。
- 日常微调台词或插入台词会在刷新后生效。在另一台电脑改稿时，先提交并推送，本机拉取后再刷新页面。新增角色/表情时同步填写剧本上方的表情表。若增删镜头、重排场景或更换镜头编号，需要同步调整程序端的剧情流程；未编排的新增镜头会明确报错，避免被静默漏掉。
- `content/script/chN.md` 是剧本唯一真源；`content/dialogue.json` 保留独立的 22 条样例及原 ID，供自由漫游使用，不转换整章 JSON。
- 玻璃杯演出的触发点暂用 SH-10 中“匡啷”“碎了一地”“白雾…轻抚”“碎片聚集回溯”等语句识别；若重写这些演出相关句子，需要程序端一起检查画面触发。普通台词和剧情推进不依赖这些关键词。

## 在这台电脑上运行

双击 **`开始游戏.cmd`**。它会启动本地服务并打开浏览器；游玩时保持命令窗口开启，结束后可以关闭窗口。

已有 Node.js 时，也可以在项目目录运行：

```powershell
node src/server.mjs
```

打开终端打印的地址，默认是 `http://127.0.0.1:4173`。默认端口被占用时会尝试后续端口。不需要安装依赖，也不需要 API Key。不要直接双击 `index.html`，否则浏览器无法读取剧情 JSON。

## 操作

- **WASD / 方向键**：移动。
- 靠近人物、调查物或出入口后 **E**：交谈、调查或切换场景，也可以点击出现的提示。靠近调查物后也可以直接点击地图中它的位置。
- **Space / Enter**：补全当前句，再按一次前往下一句；也可以点击对话框右下角。
- **Esc**：剧情模式暂停/继续；调查时关闭见闻卡。自由漫游中离开对话回到当前地图，再交谈会从当前句继续。
- **声音：关/开、音量**：控制总静音、音乐/音效/环境音音量和配乐试听。暂停会保留当前台词、幸福文字停留计时及音频播放位置。
- **F**：切换全屏。

## 代码和素材

```text
index.html          页面与游戏界面
src/main.js         场景、调查、交谈与阅读的衔接，键盘操作
src/world.mjs       四张地图的碰撞、出口、交互配置与调查原文读取
src/chapter.mjs     只读剧本适配、镜头顺序与剧情阶段
src/dialogue.mjs    只读取约定字段的对话播放器与数据校验
src/sound.js        三路音频混音、短音效、环境音与暂停
src/score.mjs       原创配乐乐谱和剧情声音编排
src/music.js        本地离线渲染配乐与循环尾音处理
src/audio-panel.js  音量、试听与浏览器设置保存
src/magic.mjs       魔法物品播放状态、光点与碎片运动
src/magic-art.js    主线与预览共用的魔法物品绘制
src/effects-preview.js 演出小剧场的分步、连续播放和暂停
src/staging.mjs     主线与小剧场共用的光影、暗角和镜头状态
src/art.js          四处像素环境、环境微动和占位人物
src/assets.js       按素材清单加载 PNG，缺图时回退到占位
src/styles.css     界面样式
src/server.mjs     零依赖的本地静态服务
assets/            程序端接入的美术素材
content/           文本机维护的剧本与对话数据（程序端只读）
docs/contract.md   两端共享的字段约定（只读）
```

立绘在左、右两侧显示。`face` 仅更新当前说话人的表情；旁白不显示姓名，并保留两边已有的表情。素材接入方式见 [assets/README.md](assets/README.md)。

原生浏览器模块已经足够验证当前切片，因此暂未引入 Phaser 或其他新依赖。地图绘制、对话数据和素材读取分开，后续可以在保留内容格式的基础上扩展。
